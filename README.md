# Inco AI Homebrew tap

Formulae for Inco AI's open-source tools.

```sh
brew tap incoai/tap
brew install splash
```

## Formulae

| Formula | What it is |
| --- | --- |
| `splash` | Local inference engine for Apple silicon, built around the model. [Repository](https://github.com/incoai/splash) · [Launch post](https://inco.ai/blog/splash/) |

## Maintaining

Formulae here are generated by their source repositories. Do not hand-edit them.

For `splash`, `make package RELEASE_VERSION=<version>` in `incoai/splash-dev`
builds the release archive, `make package-bottle` adds the prebuilt bottle, and
`make package-check` verifies the result. That writes `dist/splash.rb`. To
release:

1. Publish the archive, bottle, and checksums as a GitHub Release on the public
   mirror, `incoai/splash`, which is where the formula downloads from.
2. Copy `dist/splash.rb` over `Formula/splash.rb` here and merge.
3. On a clean machine: `brew install incoai/tap/splash && splash --version`.
4. `brew audit --strict --online incoai/tap/splash` before announcing.

Shell completion needs no extra step. The generated formula symlinks `_splash`
and `splash.bash` out of `libexec`, and because the whole tree is installed
there, the `models` helper still finds `official-models.txt` beside it.
